# homebrew-elaraops

Homebrew tap for [ElaraOps](https://elaraops.com) — Azure Blob Storage desktop app.

## Install

```bash
brew tap elaraopsio-hub/elaraops
brew install --cask elaraops
```

## Update

```bash
brew upgrade --cask elaraops
```

## Uninstall

```bash
brew uninstall --cask elaraops
```
